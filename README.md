# DS Enterprise Access Governance (`x_2098628_ds_ent_0`)

ServiceNow scoped application for enterprise access requests, approval workflows, scheduled access revocation, compliance reporting, and outbound webhook notifications.

## Key Capabilities
- **Access Governance Approval Flow**: Automates approval routing, record updates, task creation, external IdP provisioning, and outbound notifications.
- **Automated Access Revocation**: Handles scheduled and policy-driven revocation of access.
- **Compliance & Audit Reporting**: Tracks lifecycle compliance and expired pending reviews.
- **Outbound Webhook Integration**: Sends approval notifications via `sn_ws.RESTMessageV2` to a configured Discord webhook (`Spidey Bot`).
